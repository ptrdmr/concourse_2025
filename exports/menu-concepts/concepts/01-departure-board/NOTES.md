# 01 — Departure Board

**Idea.** Concourse is an airport word. This menu reads like a departures board:
one full-width scanning column, strict flush-right price rail with tabular
monospace numerals, section headers as gate tags (GATE A01 SALADS), hairline
rules, split-flap amber on near-black.

**Type.** IBM Plex Sans for names; IBM Plex Mono for prices and gate codes.

**Tone.** Precise, adult, a little cool. Not cute. Not retro bowling kitsch.
